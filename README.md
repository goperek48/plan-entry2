# The plan make.fun will carry out in public

A program that writes one plan to `/output/entry.txt`: what an AI agent can
carry out itself to turn $100 into the most money in 30 days.

## Run locally

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22+. No network, no dependencies, stdlib only.
